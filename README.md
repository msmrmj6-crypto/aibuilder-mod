# AI Builder — مود ماين كرافت (Fabric)

مود لماين كرافت جافا (Fabric، نسخة **1.21.11**) يخليك تبني أشياء بوصفها بالكلام.
أول ما أي لاعب يدخل العالم ومعنده مفتاح محفوظ، توصله رسالة بالشات تطلب منه
مفتاح OpenAI API الخاص فيه. كل لاعب يحط مفتاحه الخاص، فكل واحد يدفع على
استخدامه هو بس.

هذا المشروع **جاهز كامل** — مبني من نفس القالب الرسمي اللي حمّلته من
fabricmc.net (نفس gradlew ونفس ملفات gradle)، وبس زدت عليه كود المود.
ما تحتاج تدمج أي شي بنفسك.

## الأوامر داخل اللعبة

| الأمر | الوظيفة |
|---|---|
| `/aikey <مفتاحك>` | يحفظ مفتاح OpenAI الخاص فيك |
| `/aikey status` | يقولك إذا عندك مفتاح محفوظ (بدون ما يعرضه) |
| `/aikey clear` | يحذف مفتاحك المحفوظ |
| `/aibuild <وصف>` | يطلب من الذكاء الاصطناعي يصمم ويبني الوصف قدامك مباشرة |

مثال: `/aibuild بيت خشبي صغير بسقف مائل وباب وشباك`

## قبل لا تبني

- JDK 21 (نفسه اللي ماين كرافت 1.21.x يحتاجه).
- IntelliJ IDEA (الأفضل) أو أي IDE يدعم Gradle.
- مفتاح OpenAI API شغّال وعليه رصيد/Billing مفعّل (من platform.openai.com).
- اتصال إنترنت وقت أول بناء، عشان Gradle يحمّل Minecraft وFabric API وMojang
  mappings تلقائياً (يصير مرة وحدة، بعدها يصير محفوظ محلياً).

## طريقة البناء

1. فك ضغط هذا المشروع بمجلد.
2. افتحه بـ IntelliJ IDEA مباشرة (File → Open → اختر المجلد). IntelliJ
   بيعرف إنه مشروع Gradle ويبدأ يحمّل كل شي تلقائياً (أول مرة ممكن تاخذ
   وقت، فيها تحميل Minecraft نفسه + mappings).
3. بعد ما يخلص التحميل، شغّل مهمة `build` من تبويب Gradle على اليمين
   (Tasks → build → build)، أو من الطرفية جوه IntelliJ:
   ```
   ./gradlew build
   ```
4. الملف الناتج يطلع بـ: `build/libs/aibuilder-1.0.0.jar`

## تشغيل المود

1. ثبّت **Fabric Loader** (من fabricmc.net/use) بنسخة ماين كرافت **1.21.11**.
2. حط ملف `aibuilder-1.0.0.jar` الناتج + ملف **Fabric API** (تحمله جاهز من
   Modrinth أو CurseForge بنفس النسخة، ما يحتاج بناء) داخل مجلد `mods`
   بتثبيتة ماين كرافت.
3. شغّل ماين كرافت بالبروفايل اللي فيه Fabric، وادخل عالم جديد أو سيرفر.
4. أول ما تدخل وما عندك مفتاح، بتوصلك الرسالة بالشات.

## الإعدادات العامة

أول ما تشغّل السيرفر مرة، بينكتب ملف:
`config/aibuilder/settings.json`

فيه تقدر تغيّر:

- `model` — اسم موديل OpenAI (افتراضياً `gpt-4o-mini`؛ موديل أقوى = نتائج
  أدق لكن أغلى).
- `apiBaseUrl` — إذا تريد تستخدم سيرفر ثاني متوافق مع OpenAI (محلي مثلاً).
- `maxBuildDimension` — أقصى حجم (طول/عرض/ارتفاع) للبناية الواحدة.
- `maxBlocksPerBuild` — أقصى عدد بلوكات بكل طلب بناء (حماية من اللاق).
- `blocksPerTick` — كم بلوك يترص كل تك سيرفر (رقم أعلى = بناء أسرع لكن لاق أكثر).

مفاتيح اللاعبين نفسها تنحفظ بملف منفصل: `config/aibuilder/keys.json`.

## ⚠️ ملاحظات مهمة

- **المفاتيح تنحفظ نص عادي (plain text)** بملف على جهاز السيرفر. هذا
  مقبول بعالم شخصي (Singleplayer)، بس إذا سيرفرك مشترك، اعتبر مجلد
  الـ `config` ونسخ الباكب حساسة.
- كل لاعب يحط مفتاحه ويتحاسب هو بس على استخدامه — ما في مفتاح مشترك
  يستخدمه الكل.
- المود يتجاهل حالياً دوران/اتجاه البلوكات (يحط كل بلوك بوضعه الافتراضي)،
  وما يدعم كيانات مثل الصناديق أو اللوحات بعد — هذا نطاق النسخة الأولى.
- جودة البناء تعتمد على قوة الموديل المستخدم ودقة وصفك.

## 🔧 إذا صار خطأ بالبناء (Gradle)

أرقام إصدارات Fabric Loader / Fabric API اللي بملف `gradle.properties`
مأخوذة من نفس الملف اللي نزّلته من الموقع الرسمي، فهي مضبوطة 100% لنسخة
1.21.11 وقت كتابة هذا الملف. إذا تغيرت الأرقام مستقبلاً وطلع خطأ "could
not find":

1. افتح https://fabricmc.net/develop/ وشوف الأرقام الموصى فيها لنفس نسخة
   ماين كرافت، وحدّثها بـ `gradle.properties`.
2. لاحظ: هذا المشروع يستخدم **Mojang mappings الرسمية** (`loom.officialMojangMappings()`)
   مو Yarn — فإذا تحب تضيف كود جافا زيادة بنفسك، استخدم أسماء الأصناف
   الرسمية (مثلاً `ServerPlayer` مو `ServerPlayerEntity`، و`Component` مو
   `Text`، و`CommandSourceStack` مو `ServerCommandSource`).
